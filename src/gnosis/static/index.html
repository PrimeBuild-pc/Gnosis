Aggiungi o aggiorna sorgente

Una sorgente nuova (piattaforma mai abilitata prima) richiede un riavvio del worker per iniziare la raccolta. Abilitare/disabilitare una sorgente già esistente ha effetto immediato sulle risposte.

Stato configurazione

Serve solo il provider chat per iniziare. Le piattaforme sono facoltative e si aggiungono quando vuoi: ognuna richiede le sue credenziali qui sotto e almeno una sorgente nel tab Sorgenti.

Provider e chiavi

I campi mostrano solo un'anteprima mascherata del valore attuale. Lascia vuoto un campo per non modificarlo. Le chiavi del provider chat valgono subito; quelle delle piattaforme richiedono docker compose restart worker.
